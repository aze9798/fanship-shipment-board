帆顺报工 App

装一次，以后点桌面图标就能报工，不用再输访问码；每天 17:30 会提醒报当天的计件。

下载安装包安卓手机 · 约 100 KB · 点一下就下载

安装步骤

  1. 点上面的下载安装包。如果提示"此类文件可能有害"或"不安全"，选仍然下载。
  2. 下载完，在通知栏或"文件管理 → 下载"里点开它，选安装。
  3. 如果提示"禁止安装未知应用"，点提示里的设置，把允许来自此来源的应用打开，再回去安装。
  4. 装完打开 App，第一次输入管理员发给你的访问码（例如 FS-XX-XXXXX），之后就不用再输了。
  5. App 会问通知权限，一定选允许，不然 17:30 收不到提醒。
  6. 如果弹出"忽略电池优化"，选允许，否则提醒可能不弹。

手机品牌专属设置（重要）

小米 / 红米 如果打不开安装包，先去 设置 → 应用设置 → 纯净模式 里关掉"纯净模式"，再装。装完建议在 设置 → 应用设置 → 应用管理 → 帆顺报工 → 省电策略 选"无限制"。

华为 / 荣耀 设置 → 安全 → 更多安全设置 → 外部来源应用下载 打开。装完在 设置 → 应用启动管理 里把"帆顺报工"设为手动管理并全部勾选。

OPPO / 一加 / realme 设置 → 安全 → 安装外部来源应用 允许你用的浏览器安装。装完在 设置 → 电池 → 应用耗电管理 → 帆顺报工 选"允许后台运行"。

常见问题

  1. 打开是白屏 / 转圈：先切换一下 WiFi 和流量再打开；App 会自动换线路重试。还不行就把屏幕截图发给管理员。
  2. 收不到 17:30 提醒：检查两处——通知权限是否允许、电池优化是否已允许（按上面手机品牌的设置做一遍）。
  3. 换了手机或重装：重新输入一次访问码即可，历史报工不会丢。
  4. 访问码忘了：找管理员要。
